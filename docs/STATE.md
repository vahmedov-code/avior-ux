Добавлен параметр --timeout и безопасная классификация сетевых ошибок без вывода ключа/сырых исключений. Launcher продолжает тот же кеш с --max-calls 164 --timeout 90, без автоповторов. Одиннадцать автономных тестов прошли, включая обрыв после успеха и продолжение без повторной отправки успешного запроса. Для продолжения требуется скрытый ввод ключа локально; при диагностике живых API-вызовов не было.
