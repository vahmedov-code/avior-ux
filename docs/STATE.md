## Что показало сравнение

- Контрольные маски, повторённые в первом и расширенном срезах, совпали. Это близкие по времени срезы одного 30-дневного окна, не измерение тренда рынка.
- Широкие маски бизнеса услуг из первого среза не являются оценкой спроса ремонтных бизнесов. Ассоциации не считаются прямым коммерческим спросом, частотности пересекаются и не суммируются.
- У маски заявок на ремонт телефонов обнаружено существенное загрязнение Ростелекомом, домашней телефонией и потребительскими обращениями. Её общую частотность нельзя считать спросом смартфонных мастерских на продвижение.
- В бытовой технике есть уточнения с явным поиском покупки заявок/агрегатора. Формулировки продавцов заявок не равны спросу покупателей. Рекламные маски также содержат поиск картинок/советов.
- Для следующего прогноза ассистент предлагает приоритетно проверить бытовую технику и смартфоны; ноутбуки — отдельная дополнительная группа, электросамокаты имеют мало сигнала по выбранным формулировкам этого окна. Это не утверждённый запуск и не доказательство отсутствия годового/сезонного спроса.
- Дерево подтвердило вложенность столиц в области/агломерации и принадлежность России. Глобальные cities отфильтрованы по дереву; остаток России в отчёте рассчитан из невложенных наборов, а не собран отдельно. Столицу не складывать с содержащим её набором.
- Объём по маскам за пределами столичных агломераций есть, но выгодный регион не выбран. Москва остаётся вариантом для сравнения. Предположения о более дорогом трафике или более богатых клиентах не считаются установленными результатами. Решение отложено до прогноза/экономики; платёжеспособность не выводится только из города.
- Показатель API — последние 30 дней, а не календарный месяц и не количество людей/продаж. Отсутствующий totalCount в успешном proto3-ответе интерпретируется в аналитическом отчёте как default 0; исходные CSV с пустыми ячейками не перезаписывались. Это не признак сетевого сбоя и не доказательство отсутствия рынка.
