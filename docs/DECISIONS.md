# Решения

## Подтверждено пользователем

- 08.11.2026. Ассистент готовит наборы запросов Wordstat, пользователь запускает сбор из приложения. Ключ сохраняется локально для повторных запусков, результаты идут в общий архив. Приложение открывается с ярлыка на рабочем столе.

- 07.11.2026: аудиторию ищущих лиды/заявки рассматривать как потенциально заинтересованную в нашем предложении, не исключать автоматически; проверить конверсию отдельно.
- 07.11.2026: географию запуска определить позже по аналитике и экономике; Москву заранее не исключать и не выбирать на основании предположений о цене клика или платёжеспособности.

- 07.11.2026: добавить в исследование формулировку «лиды» для четырёх ремонтных категорий. Это уточнение исследуемого спроса, не утверждение услуги продажи готовых лидов.

- 07.11.2026: исследовательские действия в рамках задачи стоимостью до 100 ₽ включительно разрешены без отдельного подтверждения. Перед действием или пакетом дороже 100 ₽ сообщить стоимость и получить явное разрешение; не дробить пакет ради обхода порога.
- 07.11.2026: пользователь разрешил увеличить количество запросов ради предварительного изучения рынка до рекламного теста. Прежний компактный план заменяется расширенным; повторное подтверждение недорогого сбора не требуется в рамках установленного порога.

- 07.11.2026: формулировать направление услуги через поиск/привлечение клиентов из интернета на ремонт смартфонов, ноутбуков, электросамокатов и бытовой техники. Конкретная модель оплаты, продажа готовых лидов и гарантии заявок не утверждены.

- 07.11.2026: Целевая аудитория — владельцы сервисных центров и ремонтных мастерских: смартфоны, ноутбуки, электросамокаты, бытовая техника. Ищем заказчиков сайта и продвижения для их бизнеса. География рекламы и окончательные ключевые фразы ещё не выбраны.

- Под отдельный продукт нужна отдельная посадочная страница.
- Продвижение необходимо освоить и развивать как услугу вместе с сайтами.
- Git должен хранить актуальный контекст для работы в разных LLM.
- До запуска нужно исследовать спрос и выгодную географию.
- 07.11.2026: выполнить пробный запрос Wordstat перед полным сбором до 22 новых вызовов. Реализация использует общий лимит 22 для пробы и полного плана, повторно используя пробный ответ из кеша.
- 07.11.2026: сервер общий и содержит другие проекты. Главное — не задеть их. Границы работ AVIOR UX и запрет затрагивать соседние проекты и общие службы зафиксированы в AGENTS.md.

## Предложения ассистента, ещё не окончательные решения

- Размещать посадочные на текущем домене, начать с /service/; /master/ рассматривать после исследования.
- Начать с одного сегмента, не дробить небольшой бюджет между множеством гипотез.
- Использовать существующий репозиторий avior-ux для кода, общих инструкций и публичной стратегии; закрытые данные хранить отдельно.
- Цель по обороту обсуждалась как гипотеза; вывод об успешности принимать по прибыли, а не по сумме заказов. Число «один клиент на бюджет» не является рыночной статистикой.
