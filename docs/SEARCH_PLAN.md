# План подбора запросов и географии — 07.11.2026

## Согласованная аудитория

Владельцы сервисных центров и мастерских по ремонту смартфонов, ноутбуков, электросамокатов и бытовой техники. Услуги AVIOR UX для них: разработка сайта, продвижение, комплексный запуск. Конкретный состав услуги ещё не утверждён.

## Кандидаты для исследования

Ниже непроверенные формулировки для подбора семантики, а не готовая кампания и не измеренный спрос. Собрать варианты «создание/заказать/разработка/стоимость», проверить намерение, пересечения и подходящие операторы. Данные по близкой общей маске не подставлять как частотность отдельной новой фразы.

| Смартфоны | создание сайта для ремонта телефонов | настройка яндекс директ ремонт телефонов | сайт и реклама для сервисного центра |

| Электросамокаты | сайт для мастерской по ремонту электросамокатов | реклама мастерской по ремонту электросамокатов | сайт и продвижение ремонта электросамокатов |
| Бытовая техника | создание сайта для ремонта бытовой техники | настройка яндекс директ ремонт бытовой техники | сайт с рекламой для ремонта бытовой техники |

Также проверить общие B2B-формулировки «создание сайта для сервисного центра», «заказать сайт ремонтной мастерской», «продвижение сервисного центра», «реклама ремонтной мастерской». Общие и отраслевые маски пересекаются: частотности не суммировать. Общие фразы создания/продвижения без ремонтного контекста не считать гарантированным способом найти нужных владельцев.

## Отбор намерения

- Заказ сайта/настройки рекламы/продвижения — основная коммерческая группа.
- Поиск идей «как привлечь клиентов в сервисный центр» — отдельная информационная гипотеза, её не смешивать с покупкой услуги.
- «Ремонт телефона рядом», «замена экрана цена», «ремонт холодильника на дому» приводят конечных клиентов ремонта и не относятся к нашей рекламной кампании.
- Исключать обучение, вакансии, скачивание, самостоятельный ремонт и нерелевантный поиск брендов по фактическим фразам. Минус-слова проверять на пересечения: нельзя целиком минусовать «ремонт телефонов» или другие названия целевых специализаций, входящие в B2B-запросы.

## Региональное сравнение — предложение, не решение о запуске

Сравнить одинаковые очищенные группы и параметры прогноза: Москва + Московская область; Санкт-Петербург + Ленинградская область; Россия без этих столичных регионов. Последнюю группу затем рассматривать по отдельным городам, чтобы общая цифра не скрывала различия. При детализации не складывать вложенные регионы.

Фиксировать период, объём трафика и минус-фразы, чтобы сравнение было сопоставимым. Поля результата: регион, направление ремонта, тип нашей услуги, ключевая фраза, спрос/охват, прогноз показов, кликов, средней цены перехода и расходов. Дешёвый клик не доказывает выгодного заказчика; окончательный выбор проверяется качественными заявками, оплатами и затратами исполнения.

География нашей рекламы относится к владельцам мастерских, которым продаём услуги. География будущих кампаний клиентов по ремонту — отдельная настройка каждого клиента; её не переносить автоматически на AVIOR UX.

## Порядок

1. Сформировать и очистить B2B-список по четырём направлениям.
2. Перед новым Wordstat-сбором согласовать отдельный лимит: предыдущий план завершён, текущий документ не разрешает новые вызовы. Использовать новый внешний кеш для нового среза.
3. Снять сопоставимый прогноз Директа по регионам и группам. Учётные данные Wordstat не означают настроенный доступ к прогнозу Директа.
4. Выбрать первую группу/географию и оффер, затем подготовить лендинг и условия ограниченного рекламного теста.

Новые API-вызовы, рекламные кампании и изменения сайта при составлении этого плана не выполнялись.

## Дополнение: язык задачи владельца и сопоставление с первым срезом

Пользователь просит формулировать услугу через привлечение клиентов из интернета на ремонт. Добавлены намерения «привлечение клиентов», «заявки», «как привлечь клиентов». Они не равны покупке сайта: возможны бесплатные советы, поиск работы, готовых лидов или диспетчеризации. Эти намерения проверяются отдельно, модель продажи готовых заявок не утверждена.

Подготовленный второй конфиг — tools/demand/research-repair-acquisition.json. В нём 20 масок (четыре специализации × пять намерений: сайт, реклама, привлечение клиентов, заявки, советы) и две исходные маски для сопоставимости: «сайт для сервисного центра», «реклама сервисного центра». До 22 topRequests, Россия (225), все устройства, 100 уточнений, без глобального cities. План проверен без API. Запуск и новый лимит требуют отдельного согласования; прежний лимит использован. Новый срез должен иметь отдельный внешний кеш и результаты.

Первый срез остаётся базой инструментального спроса. Нового численного сравнения пока нет; ни одна частотность старого общего запроса не назначается новой фразе. Одинаковые маски между срезами нужны для сопоставимости, а не для выводов о рыночном тренде по двум близким скользящим окнам. После получения и очистки новых данных — сопоставимый прогноз Директа по географии, затем выбор группы и лендинг.
