# AVIOR UX

Сайт услуг разработки и проект проверки спроса на сайты с дальнейшим продвижением.

## Быстрый вход для новой модели

Прочитай [AGENTS.md](AGENTS.md), [состояние](docs/STATE.md), [стратегию](docs/STRATEGY.md), [решения](docs/DECISIONS.md) и [передачу работы](docs/HANDOFF.md). Проверь ветку и свежие коммиты; не опирайся только на память чата.

Сайт: https://ux.avior.moscow/

Код сайта: React + TypeScript + Vite. Команды: `npm ci`, `npm run dev`, `npm run build`. Сборщик Wordstat и инструкция: [tools/demand/README.md](tools/demand/README.md).

## Работа в нескольких моделях

Каждая задача — отдельная ветка и PR. В PR указывать проблему, изменение, проверки и ограничения. После принятия изменений следующая модель начинает со свежего main. Пока PR с исходным контекстом не объединён, указывать модели его ветку явно.

Стартовый запрос для любой модели:

> Работаем над vahmedov-code/avior-ux. Открой актуальную рабочую ветку, прочитай AGENTS.md и четыре документа в docs. Коротко подтверди текущую цель, блокеры и следующую задачу. Затем выполняй указанную мной задачу в отдельной ветке и обнови передачу работы. Гипотезы не выдавай за измеренные результаты. Если доступа к репозиторию нет, сообщи об этом.

Само наличие файлов не гарантирует, что любая модель их прочитает: начальный запрос и доступ к GitHub нужны.
